Reserva tu cancha en minutos

Sistema web MVC para la gestión de canchas deportivas en Lima: reservas con bloques horarios, pago, clases con cupos y un panel ERP para la administración. Construido con Java 21, Spring Boot, Thymeleaf y PostgreSQL.

Entrar como cliente Entrar como administrador

Cuentas demo: gdiaz (cliente) · admin (administrador) · clave Password123

Qué hace

Los seis módulos del sistema, cada uno con su pantalla.

Acceso

Login y registro

Login por usuario o correo validado contra la BD. Registro con DNI, nombres, apellidos, usuario, clave y perfil; la cuenta nace pendiente y solo el administrador la activa.

Canchas

Catálogo con filtros

Búsqueda por deporte, distrito y rango de precio. Detalle con servicios, reglamento y calendario de bloques de 1.5 h.

Reservas

Pago y confirmación

Subtotal + cargo por servicio del 10 %. Un índice único en la base de datos impide reservar dos veces el mismo bloque.

Historial

Mis reservas

Pestañas Próximas / Pasadas / Canceladas, con cancelación y reprogramación en autoservicio.

Clases

Clases deportivas

Clases dictadas por entrenadores con control de cupo e inscripción en línea.

ERP

Panel de administración

KPIs, ingresos por mes y por cancha, y CRUD de usuarios, canchas, clases e inscripciones con listas desplegables cargadas desde tablas de la BD.

Arquitectura MVC

Model: entidades JPA + servicios · View: plantillas Thymeleaf · Controller: Spring MVC (+ API REST).

Navegador ──▶ @Controller (Spring MVC) ──▶ @Service ──▶ Spring Data JPA ──▶ PostgreSQL 16 │ ▲ └──▶ Thymeleaf (templates/*.html) ◀── Model ────┘ JS (fetch) ───▶ @RestController (/api/**) · Spring Security (JWT en cookie HttpOnly + CSRF)
